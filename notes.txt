Inlining (Function Inlining)
------------------------------
    Definition: Replacing a function call with the actual body of the function.

    Why: Removes function call overhead, makes execution faster.

    Remember: Call replaced with code.

Copy Elision
-------------

    Definition: Compiler optimization that avoids making unnecessary temporary copies of objects.

    Why: Improves performance by constructing directly in the target variable.

    Remember: No extra copy → object built directly.

Inline caching
--------------

    Definition: Runtime optimization (in JS engines) that caches the location of properties/methods after first lookup.

    Why: Makes repeated property access faster in dynamic languages.

    Remember: Cache property access for speed.

   -> Lexical environment exists so that JavaScript knows where to look for a variable’s value.
      JavaScript creates lexical environments for global scope, function scope, and block scope.
      Each lexical environment has its own environment record and a reference to its outer lexical environment,
       which defines the path JavaScript follows when resolving variables.

   -> example : 
      global has outer reference as null
      function a in the above example has outer reference as global 
      function c has outer reference as a's local environment

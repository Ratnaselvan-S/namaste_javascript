Promises.all 
------------
    -> when we required to load multiple api call at tha same time 
    -> use cases we know in the iqagent promise.all is used to determine the loading state of loader ,once all the api call is done then we push the loader out 
        of it 
    
what if the prmose.all inside one api call is rejected ??
    -> then all the promise will throw an error even if one is failed

promise.allSetteled
-------------------

   ->both are same and even if one fail ,it gives result and says that one has failed ,like promise.all it wont throw any error 
   -> example scenario:suppose if 5 card api call need to take place and only 4 cards succeeded then show four cards 


promise.race
--------------
   ->this is as the name suggest which promise gets resolved first that promise will be given as result
   -> so what if the first race promise was rejected ,so error will be thrown

promise.any
-------------
   -> here this is same functionality as promise.race ,the key difference is ,whatever promise get first resolved is winner,like if first reolved code is error then it 
      will wait for the next first promise which is resolved succesfully ,it wont throw error on if the first reolved promise is error 

   -> suppose if every promise is reolved error then it return aggregate of error which looks like [err1,err2,err3]



Uncaught error is something we didnt catch the error ,we should not have uncaught error 


promise.all
------------

const p1=new Promise((resolve,reject)=>{
    setTimeout( ()=>{
        resolve("P1  success")
    },3000)
})

const p2=new Promise((resolve,reject)=>{
    setTimeout( ()=>{
        resolve("P2  success")
    },1000)
})
const p3=new Promise((resolve,reject)=>{
    setTimeout( ()=>{
        resolve("P3  success")
    },2000)
})


Promise.all([p1,p2,p3]).then((res)=>console.log(res)).catch(err=>console.error(err))

result:
-----------
   [
    "P1  success",
    "P2  success",
    "P3  success"
]

promise.allSettled
------------------

const p1=new Promise((resolve,reject)=>{
    setTimeout( ()=>{
        resolve("P1  success")
    },3000)
})

const p2=new Promise((resolve,reject)=>{
    setTimeout( ()=>{
        reject("P2  success")
    },1000)
})
const p3=new Promise((resolve,reject)=>{
    setTimeout( ()=>{
        resolve("P3  success")
    },2000)
})


Promise.allSettled([p1,p2,p3]).then((res)=>console.log(res)).catch(err=>console.error(err))


result:
---------
[
    {
        "status": "fulfilled",
        "value": "P1  success"
    },
    {
        "status": "rejected",
        "reason": "P2  success"
    },
    {
        "status": "fulfilled",
        "value": "P3  success"
    }
]

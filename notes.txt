   -> The Memory Heap is where JavaScript stores objects, functions, arrays, and reference-type values.
            - Primitives (number, string, boolean, null, undefined, symbol, bigint) are usually stored in the stack (with their value directly stored).
            - When you assign an object or function, the reference (pointer) is kept on the stack, while the actual data lives in the heap.

Shadowing 
-----------

let name = "Ratna"; // outer scope

function greet() {
  let name = "Copilot"; // shadows outer 'name'
  console.log("Hello, " + name); // prints "Hello, Copilot"
}

greet();
console.log("Outside: " + name); // prints "Outside: Ratna"

def:
    If we have same named variable outside the block, then block variable will shadowed outside block variable.

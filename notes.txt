So where does shadowing come in?

Shadowing is not a separate mechanism — it’s just a name for the situation where a local declaration prevents access to an outer variable with the same name.

👉 Example:

let name = "Ratna";  // global

function greet() {
  let name = "Copilot"; // new variable in local EC
  console.log(name);    // local 'name' is found first → hides outer one
}
greet();


When the engine resolves name inside greet():

Step 1: Looks in greet()’s local environment → finds "Copilot". ✅ Done.

Step 2: It never even goes to outer scope because it already found a variable with that identifier.

Result → the outer name is invisible inside this scope = shadowed.
